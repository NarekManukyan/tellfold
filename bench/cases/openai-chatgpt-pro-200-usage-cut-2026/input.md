# OpenAI restructures ChatGPT Pro: new Pro 500 tier, reduced Pro 200 allowance

## Who is announcing

OpenAI makes ChatGPT and the Codex coding agent. Its consumer plans are ChatGPT Plus ($20/month) and a set of Pro plans for heavy users. The **Pro 100** ($100/month) gives 5x the Plus usage allowance, and **Pro 200** ($200/month) has until now given 20x. Pro usage covers ChatGPT Work (agent tasks), Codex coding sessions and messages to the top GPT-6 Pro model. Many Pro 200 subscribers are developers and professionals who run long, token-heavy coding and agent jobs. In mid-September 2026 OpenAI paused new Pro 200 sign-ups, citing demand for its new GPT-6 Astra model.

## What was announced

At its DevDay event on 29 September 2026, OpenAI announced a new Pro line-up:

- **Pro 500 (new, $500/month):** 25x the Plus allowance and the only plan with "Ultrafast" mode (much faster generation in Codex).
- **Pro 200 ($200/month, price unchanged):** reopened to new sign-ups, with its included allowance changed from **20x to 10x** Plus for Work and Codex usage. Weekly GPT-6 Pro messages in ChatGPT go from 200 to 100. The rolling five-hour usage window is removed, and usage is now measured weekly. After the allowance runs out, users can buy extra credits.
- **Pro 100 ($100/month):** unchanged at 5x.
- **Existing Pro 200 subscribers** keep their current allowance through **29 October 2026** if their subscription stays active. The new allowance applies from 30 October. They also get a one-time grant of 62,500 usage credits (about $2,500 in value at OpenAI's rates), valid until 31 December 2026.
- At the same event OpenAI cut API prices for GPT-6 Sol and GPT-6 Luna by roughly half. GPT-6 Astra's API price is unchanged.

**Stated reasons:** OpenAI said new DevDay features need a lot of compute, and that its models have become more efficient. Codex lead Thibault Sottiaux said the Pro plans are now priced against API list prices, so future API price cuts pass through to subscribers. He acknowledged on X that, measured at list prices, the new Pro 200 comes to about half the old value. OpenAI said Pro 200 will not return to a five-hour window, and that chats with its new "Dot" assistants will not count against usage.

## How it was communicated

Announced on stage at DevDay on 29 September 2026, with an email to Pro subscribers, an updated Pro plans help page and posts on X by OpenAI staff.
