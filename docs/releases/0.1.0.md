# Tellfold 0.1.0

The first public build of Tellfold for Mac.

- Describe a product, price change or announcement, ask a question, and watch a simulated crowd react over several rounds.
- A report answers the question, with the simulated posts as evidence.
- The engine is built in: no Python or uv needed. Claude Code must be installed and signed in.
- Tellfold checks for updates once a day; you can also use Tellfold > Check for Updates….
