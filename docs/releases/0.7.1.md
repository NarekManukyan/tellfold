# Tellfold 0.7.1

- **One engine.** Tellfold now runs only its built-in engine. The old Python engine and its `uv` setup screen are gone, so there's nothing extra to install. Settings > Advanced > Engine path still lets you point the app at another Tellfold engine build.
- **Update checks are counted.** The app checks for updates about once a day, as before. Those checks now go through a small counter of ours, which records the date and the app version and nothing else. There are no IP addresses, no identifiers and no cookies. It's how we can tell roughly how many copies are in use.
- **An easier install.** The disk image opens as a window with Tellfold and the Applications folder, so you drag one onto the other like most Mac apps.
