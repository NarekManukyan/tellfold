# Tellfold 0.7.2

- **A better call on the overall reaction.** The report now takes its overall direction (positive, negative or mixed) from the planner's view of who the news reaches and how each group is likely to lean. The crowd still runs, and its posts, objections and quotes still make up the report; a crowd that leaned the other way shows up as dissent. On our 43-case test, the direction was right 65% of the time, up from 55%. `tellfold run --crowd-direction` keeps the old behaviour.
- **Local models through Ollama work properly.** Crowd replies are held to valid actions, sized to the batch, and stopped with a clear error if a model runs away instead of being sent back for repair. With the planner on Ollama, graph extraction no longer gets stuck repeating itself, and the report no longer times out. Ollama doesn't think by default; turn on thinking if you want it, and those calls get more time.
- **Runs started outside the app show their progress.** A run started from the command line or through the MCP server now shows how far it has got, instead of "finished without a report" while it's still going.
- **Studies keep each version separate.** When a second version reuses the first version's people, they no longer carry over details that only the first version had.
- **No more stuck runs after sleep.** A model call that was running when the Mac went to sleep now times out after it wakes, instead of waiting forever.
