# Tellfold 0.4.0

- **A much smaller app.** The simulation engine has been rewritten in Rust. Tellfold used to carry its own copy of Python, which made up almost all of the 196 MB download. The engine is now a single 13 MB program, and it starts faster when you open the app.
- **Nothing else changes.** Runs, reports, studies, Check it, branches and rewrites work as before, and runs you made with earlier versions open as they are.
- **PDF seeds** are read by a new PDF reader. A PDF's text can come out with slightly different line breaks or ordering than before, so the same PDF may give a slightly different cast.
