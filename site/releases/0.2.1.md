# Tellfold 0.2.1

- **Add a whole folder.** In New simulation, choose or drop a folder and Tellfold adds every .md, .txt and .pdf in it and its subfolders, skipping hidden files and dependency or build folders. A run can now take up to 100 files and 100 MB in total.
- **Big document sets start much faster.** Mapping the topic now reads at most 64 passages: the opening of each document and the passages most relevant to your question. A large docs folder used to need over a hundred model calls before the crowd started.
- **Cursor works.** Runs with Cursor Agent no longer fail on its "Workspace Trust" prompt.
- **Less memory.** Tellfold now stops the background processes some AI tools leave running after each call. With Cursor these used to pile up to several gigabytes during a run.
- **Other AI tools.** Fixes for current versions of Gemini CLI (folder trust), Qwen Code (it no longer approves edits or commands on its own), OpenCode 2 and Ollama (long prompts are no longer cut short).
- Adding a folder no longer freezes the window while it is read.
