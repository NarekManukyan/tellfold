# Tellfold 0.2.0

The first public release of Tellfold for Mac.

- Describe an announcement, a price change, a new rule or a plan, ask a question, and watch a simulated crowd react over several rounds. A report answers the question and cites the posts behind every claim.
- Works with the AI tools you already have. On first launch Tellfold finds Claude Code, Codex, Gemini CLI, Cursor, Ollama and others on your Mac and suggests one. You can change it any time in Settings › Agents.
- Runs on macOS 15 or later, on Apple silicon.
- Two finished example runs are built in, so you can explore a report before running your own.
- Pick the language the crowd posts in, or start from a template.
- See how many model calls a run will make before you start it, and how many it used afterwards.
- Every citation in the report is checked against the run.
- Export a report as a PDF or a web page.
- The engine is built in: no Python to set up.
- Tellfold checks for updates once a day; you can also use Tellfold › Check for Updates….
