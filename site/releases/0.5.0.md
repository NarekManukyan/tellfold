# Tellfold 0.5.0

- **Check the cast before the run.** Tick "Review the cast before the run" on the New Simulation sheet, and the run stops once its people are made. You can see who they are, remove someone, change a bio, a stance or a camp, or describe a group in a sentence and have it added. Start the simulation when the cast looks right. "Later" leaves the run waiting, and "Check the Cast" in the toolbar brings the editor back.
- **Saved audiences.** "Save as Audience" keeps a cast, so another run can start with the same people. "Manage…" on the New Simulation sheet renames or deletes them.
- **Everyone gets a turn.** Someone with a strong view, for or against, no longer sits out the whole run. Every camp posts in the first round, and nobody who feels strongly is left out for more than two rounds in a row. New runs from the app work this way. Runs you made before don't change, and neither do new versions of them.
- **Share cards.** A finished report can become an image with its headline, its confidence, the mood by round and two quotes, in light or dark, sized for a post or a square. Copy it or save it as a PNG from the report toolbar or File › Share Card….
- **Send a run to someone.** File › Export Run Bundle… saves a finished run as a `.tellfold` file. Opening the file on another Mac adds the run read-only, with its report, its people and every post. It carries no prompts and no paths from your Mac.
- **Use Tellfold from Claude Code and other tools.** `tellfold mcp` lets Claude Code, Claude Desktop, Cursor and other MCP clients start a simulation, wait for it, read the report, question the crowd or one person, compare two drafts and check a result. Runs started this way show up in the app. The docs explain the setup, and the repository has a ready-made Claude Code skill.
