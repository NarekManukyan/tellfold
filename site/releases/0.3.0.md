# Tellfold 0.3.0

- **Try another version.** On a finished run, choose "Try another version…", edit the text and run it on the same crowd. Tellfold doesn't build the cast again, so the run is cheaper and the comparison is fair. The new Studies section shows both sentiment curves on one chart and the camps side by side. A short comparison then says which draft did better and why, citing posts from both runs.
- **Check it.** "Check it (3 runs)" runs the same question again with the same people. It tells you in plain words what held and what didn't, gives a verdict (consistent, mixed or unstable), and shows the range of sentiment across runs in each round. Tellfold tells you how much extra model usage this takes before it starts.
- **Suggest a better version.** A button on the report rewrites your text based on how the crowd reacted. Each change links to the posts behind it, and you see what was kept on purpose and a line-by-line diff. "Test this version" runs the new text on the same crowd.
- **Branch from any round.** "Branch from Round N…" in the round scrubber asks "what if?" Change, remove or add what happens after that round, and the branch continues from the same point as the original. Runs made before 0.3.0 can branch from round 0 or from their last round.
- **What to do next.** Every report now ends with three to six concrete steps (keep, change, add, drop or test). Each step says why, who it's for and which posts it's based on.
