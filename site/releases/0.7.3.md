# Tellfold 0.7.3

- **The report calls good news good.** When the planner expects a positive or a negative reaction, the report's title, summary and prediction now say so plainly. Pushback from a smaller group is described as dissent or a risk to watch, so it no longer turns the whole report into a hedge. On our 43-case test the direction was right 69% of the time, up from 65%. On 13 new cases written after this change, it was right 77% of the time. Asking the same model directly got 88% on those (too few cases to call that gap certain), so treat Tellfold as a rehearsal, not a forecast. Every result is in [ACCURACY.md](https://github.com/NarekManukyan/tellfold/blob/main/docs/ACCURACY.md).
